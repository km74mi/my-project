# リール「面談導線01」編集指示書

個別設計面談につなげるリール。台本は完成済み。**編集は Codex に任せる**(2026-10-10 決定)。この指示書だけで編集できるように書いている。

## 目的と導線
- 見る人: 好きで始めたのに、売上のために無理しているキャバ嬢さん(特に昼と夜を掛け持ちしている人)
- 導線: リールで「無理」とコメント → DM で特典 note の URL が届く → 最後まで読むと個別設計面談に申し込める

## 形式
| 項目 | 内容 |
| --- | --- |
| 長さ | 30秒 |
| 画面 | 縦型 1080×1920、30fps |
| 声 | なし(アフレコなし) |
| 顔 | 出さない(顔の映らない映像だけ) |
| テロップ | 画面中央。1行13文字以内、最大2行 |
| 音 | 動画は**音なし**で書き出す。流行りの音源は Instagram に投稿するときにアプリで付ける |
| 型 | 型B(`.claude/skills/reel-edit/kata/kata-b.json`)。テロップだけで語るストーリー型。1枚平均約1秒で切り替える |

## ファイル
- `telop.srt` — テロップの文言と秒数(CapCut PC版の「ローカル字幕の読み込み」で取り込める)
- `telops.json` — 同じ内容に「構成(フック・転機など)」を足したもの。`reel.py` の `plan.json` の `telops` にそのまま使える
- 素材(背景映像・LP の切り抜き画像・アカウント案内)は**コミットしない**。リポジトリ直下の `reel-edit/素材/` に置く(`.gitignore` 済み)

## 編集の手順
1. 背景映像を `reel-edit/素材/` から選び、上の表の秒数に合わせて切り出して並べる。縦型 1080×1920 に切り抜いてそろえる。切り替えはテロップの切り替えに合わせる(音源の拍が分かれば拍に合わせる)。
2. テロップを入れる。次のどちらかで進める(どちらにするかはユーザーに確認する)。
   - A: 背景だけの動画を書き出し、テロップは CapCut PC版で `telop.srt` を読み込んで入れる(見た目は CapCut で整える。スタイルは一度決めたら保存する)
   - B: テロップまで焼き込んだ完成版を書き出す(`reel.py render`、型B)
3. 0:27.5 からの約2.5秒に、アカウント案内と LP の切り抜き画像を重ねる。LP は個別面談LPや切り抜きだけで、講座LPの全体は出さない。
4. 音なしで書き出す。音源は Instagram で付ける(CapCut の曲を使うと Instagram で音が消されることがある)。
5. 書き出す前に、編集計画(どの映像をどこに置くか、テロップ)を表でユーザーに見せて OK をもらう。

## 守ること
- **テロップの文言は変えない。** 直したいところがあればユーザーに確認する。台本を決めた理由は `.claude/knowledge/reel-auto-edit.md` にある。
  - 「アフターは断らない」が正しい(自分の意思で行っていた。「断れない」ではない)
  - 夜一本の子を下げる言い方は足さない。メッセージ部分で「掛け持ち」という言葉を足さない
  - 「無理しなくても売上はつくれる」は使わない
  - お客様への返しのセリフ(「ごめんな」など)は足さない。営業っぽい言い方(「来てよ」など)もしない
- 顔・他の人・お店が特定できるものを映さない。
- このリポジトリは公開。素材の動画・画像・書き出した動画はコミットしない。
- テロップは1行13文字以内、最大2行(`.claude/skills/reel-judgment/SKILL.md`)。

## 道具
`.claude/skills/reel-edit/SKILL.md` に手順、`.claude/skills/reel-edit/scripts/reel.py` に FFmpeg を使うスクリプトがある(`check` / `clip` / `analyze` / `plan` / `render`)。ただし `render` は素材が1本の前提なので、複数の映像をつなぐときは先に FFmpeg で背景を1本にまとめてから使う。
