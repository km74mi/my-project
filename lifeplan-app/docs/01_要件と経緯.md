# 01 要件と経緯

## 何のためのアプリか

- 講座の受講生(キャスト)に、**今の自分のお金の状況を数字で見てもらい、自分で気づいてもらう**ためのアプリ。
- 受講生全員にやってもらう想定。お金のフィードバック(受講生管理シートのお金の欄)は希望者だけ。アプリの数字をシートに反映する予定はない。
- 当初は「講座の特典⑨」として企画。画面上の「特典⑨」の表記は最終的に削除した。

## 根拠にしたデータ(公式LINEアンケート 34人)

| 悩みの種類 | 割合 | 順位 |
| --- | --- | --- |
| 接客・働き方が自分に合っているか不安 | 53% | 1位 |
| お金の使い方・貯め方 | 32% | 2位 |
| 相談できる人がいない | 15% | 3位 |
| 昼夜掛け持ちの体力・生活リズム | 0% | 最下位 |

- 「稼いだ分を使ってしまい貯金できない」が **62%** で断トツ。
- → 当初は体力面を重視していたが、アプリは **「貯金できない」に直接刺さる設計**にする。

## ペルソナ「あい」

- 24歳。貯金はできているが(150万円)、ゴールが見えない。
- お金の知識がない(投資と預貯金の違いも分からない)。
- 稼いだ分を使ってしまう散財パターン。
- アプリの入力例はこの人の設定:夜の手取り月30万円、30歳で卒業、28歳で自分のお店(600万円)、卒業後の手取り月25万円、つい使ってしまうお金 月6万円。

## 入れるべき要素(壁打ちで決めたこと)

1. **貯金目標の逆算**:将来必要な金額 → 月々の貯金額 → 必要な売上・指名数(講座本編06と連動)
2. **「使ってしまう」を防ぐ仕組み**:収支の見える化、「何に使ったか」の振り返り
3. **キャバを続ける期間と、その後の展望**:独立・スナック・ラウンジ・昼職など、卒業後のキャリアも含めたライフプラン
4. **ゴールの言語化**:「何のために貯めてるか分からない」をなくす目的設定
