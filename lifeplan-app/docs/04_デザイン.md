# 04 デザイン

## 方針

- **「みずき相談ルーム」(前回のセッションで作った、みずきさんの GPTs 風の相談アプリ)と同じ見た目**にそろえる。
- `km74mi/codex-practice` の `DESIGN_GUIDELINES.md` の考え方を適用:
  - 主役を一つ決める(結果画面は「今月貯めたいお金」が主役)
  - 柔らかい色でも文字ははっきり読ませる
  - 装飾に理由を持たせる(枠・帯・色は情報の区切りや状態を示すときだけ)
  - 地方キャバ嬢のリアル、親しみやすさ、自然な関西弁、少しのユーモア
- 言葉づかい:画面の説明・解説文は標準語。みずきさんの吹き出しだけ関西弁(相談ルームと同じ)。
- 責めない言い方にする(「足りません」より「ここを目指そう」)。目安であることを添える。

## グラフの色(色覚の違いにも配慮して検証済み)

Claude の `dataviz` スキルの `validate_palette.js` で、明るさの帯・彩度・色覚の違いでの見分けやすさ・背景とのコントラストを検証した。

| 用途 | ライト | ダーク |
| --- | --- | --- |
| 収入 / 支出 / 叶えたいこと | #2A78B8 / #9A3F55 / #B8862C | #4A90D0 / #C0566E / #A8822E |
| 2本の線の比較(いまのプラン / 比べる線) | #9A3F55 / #B8862C | #C0566E / #A8822E |

- 最初に試した「緑と赤」「青緑」系は、色覚の違いで見分けにくい・彩度不足で不合格だったため、青・ローズ・ゴールドにした。
- 状態の色(良い=緑系、要注意=赤系)は、アクセントとは別に `--good` / `--bad` で持つ。色だけでなく文字(「目安クリア」「!」など)でも示す。

## グラフ作りで気をつけたこと

- 2つの目盛りを持つグラフ(左右で単位が違う)は使わない。収支と貯金は別のグラフに分けた。
- 大きすぎる出費(開業600万円など)は目盛りの外に出し、「枠外」と金額を書いて、ほかの年の棒がつぶれないようにした。
- 円(お金のかたまり)は重ならないよう横に並べ、収入は「夜のお仕事/卒業後/年金」の人生の区切りでまとめた。
- ツールチップはカーソルの反対側に出して、選んだ棒を隠さない。スマホでは指を離しても残す。

## 確認の仕方

スマホ幅 390px で、ライトとダークの両方を撮影して目で確認(`scripts/check.js`)。横スクロールが出ていないこと(scrollWidth=390)も確認。
