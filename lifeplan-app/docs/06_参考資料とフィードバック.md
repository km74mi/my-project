## 参考にした画面(画像で共有してもらったもの)と取り入れたこと

| 参考画面 | 取り入れたこと |
| --- | --- |
| ライフプラン/ライフイベント/キャッシュフロー表のタブ | 結果画面の4タブ、収入(上)と支出(下)の棒グラフ、金額を円の大きさで見せる図、横に年・縦に項目の表 |
| GLiP(家族の年齢と学校の時期の帯、充足率の円グラフ) | ライフステージの帯、3つの充足率の円 |
| カーソルで「73歳 世帯収入・生活費・住居費・貯蓄」が出るグラフ | その年の内訳が出るツールチップ |
| 10年ごとの収支/貯蓄額、「支出が収入を超える」「!」 | 10年ごとの収支グラフ、「!」の目印とチェックポイント、自動の解説文 |
| ライフプランの診断結果と、積立投資額・期間を選んで再計算 | 「数字を変えて未来を見てみる」スライダー |
| 診断したライフスタイル条件と、条件別のアドバイス、インフレの注意書き | 「診断した条件」とアドバイス、注意書き |

- 左右で単位が違う2つの目盛りのグラフ(参考画面に多かった)は、読み間違いやすいので使わず、グラフを分けた。

## 受講生専用管理シート(Google スプレッドシート)の確認メモ

シート構成:パーソナル情報、3ヶ月パーソナルプラン(接客・売上/お金)、1〜3ヶ月目(接客・売上)、1〜3ヶ月目(お金)。

Claude からの指摘と、ユーザーの方針:

| 指摘 | 方針 |
| --- | --- |
| 「夜職の給料」が売上額とつながっていないか確認 | 目で見える数字として扱いたいので、それでよい |
| 「つい使ってしまったお金」の欄がない | 欄を作る。横に「使ってよかった/なくてもよかった」の欄も検討 |
| 給料を手取りで書くか総支給で書くか | 書く人によってでよい(「もらった額」が分かりやすい) |
| 「貯金できた金額」が2か所にある | シート作り直しのときに検討 |
| アプリの結果を書く欄 | 反映はしない。アプリは見て気づくためのもの |
| 共有の設定(リンクを知っている人が見られる形) | 受講生ごとにコピーして、本人とみずきさんだけに共有するのがおすすめ(未対応) |

- シートは基本「接客」で使う。お金の欄は希望者だけ(見られたくない人に強制しない)。
- シートはあとで作り直す予定。
