# 新しい発信のコンセプト(2026-11 に固めた)

公開リポジトリなので、本人の今の状況(お店・収入・住んでいる所・行き先など)はここに書かない。詳しい中身はドキュメント「新アカウントのコンセプト案」(Claude Docs、タブ「コンセプト最終版」)にある。リンクはユーザーに聞く。

## 決めたこと
- 一言:「キラキラしたいのに、キラキラできない。32歳現役キャバ嬢のリアルと挑戦」。今までの「キャバ嬢の日常」を、もっとリアルに、理想に近づいていく挑戦の日常にする。
- 100日企画・100投稿・期限は**やめた**(一度考えたが取り下げ)。ありのままを発信する。
- ゴールは数字ではなく「理想の夜」を叶えること(自分のお客様でいっぱい、ヘルプの子がいる、シャンパン、心から楽しいお酒、無理なく帰る)。物語の軸は「ライバルは一番売れていた頃の自分」。
- 昔のがむしゃらなキラキラに戻るのではなく、信頼関係と仲間がいる新しいキラキラを目指す。
- 見てほしい人: 30歳前後・地方・夜職(昼夜の掛け持ちを含む)で、年齢や仕事を理由に輝くことをあきらめている女性。
- **説教しない。** 「年齢にとらわれず挑戦しよう」「頑張ろう」のような上からの言葉は使わない。立ち位置は横で一緒にあがく人。ただし自分のことを「32歳からでも頑張りたい」と言うのは OK(世間では遅いと思われる年齢から挑戦する姿が強み。2026-11 ユーザー確認)。NG なのは見る人に向けて年齢の話をすること。
- 投稿の柱: リアル / 挑戦 / 自分磨き / 本音。どの投稿も「理想の夜に近づく一歩」として見せ、レシピや宅トレも単独のやり方投稿にしない。
- 台本の言葉づかい: 本人の話し方に合わせる。「〜へん」「いいひん」「足りひん」は使う。大阪弁の「行かれへん」「飲まれへん」「おらん」は使わない(2026-11 ユーザー指摘)。呼び方は「お客様」「キャスト」にそろえる。関西弁と標準語が1行に混ざるのは本人の話し方なので直さない。
- 見せ方: ほぼ垂れ流しのリアルが一番反応がいい。明るく「笑える」(笑われるではない)、本音の回はしっとり。アフレコで関西弁、顔出しなし、NG なし・嘘をつかない。
- 接客の基本は友営のまま。色恋は「検証」として試す。
- 店のアカウントは作らない。帰ってきてからの発信の仕方は、発信しながら探す。
