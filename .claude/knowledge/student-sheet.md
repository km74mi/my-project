# 受講生専用管理シート(Google スプレッドシート)

講座生に渡す3ヶ月のシート。URL は公開リポジトリに書かない(ユーザーに聞く)。

## 編集に必要なもの
- Google Sheets コネクタ(claude.ai/customize/connectors で追加 → 新しいセッションで有効)。Google Drive コネクタだけでは既存ファイルを直せない。新しいファイルを作るとリンクが変わるので、ユーザーが選んだときだけにする。

## 色は講座の LP(Canva)に合わせる(2026-09 決定)
参考にした Canva デザインは「講座LP」と「個別設計面談LP(申込導線)」の2つ。サムネイルから色を拾った。ライフプランアプリ(ローズ×ゴールド)とは別。
2つに共通する文字色・クリーム・ゴールドを土台にして、帯は面談LPのモカ/ゴールドブラウン(白文字が読める濃さ)、差し色は講座LPのピーチにする。

| 役割 | 色 | 出どころ |
| --- | --- | --- |
| シートのタイトル帯(白の太字) | #8A6C4E(モカ) | 面談LPの「形式」「時間」ラベル・ボタン |
| 区切り見出しの帯(白の太字) | #A88A5A(ゴールドブラウン) | 面談LPの「STEP 01」帯 |
| 表の項目行 | #EFE8DC(ベージュ) | 面談LPの左側の箱 |
| 自動計算の欄 | #F7F3EC(クリーム) | 両LPの背景 |
| 入力する欄 | #FFFFFF(白) | 両LPのカード |
| 罫線 | #DCC896(ゴールド) | 両LPの細い線 |
| 「目安クリア」などの印 | #C6A85A(ゴールド)の面に #544842 の文字 | 面談LPの「無料」 |
| 差し色(シートの見出しタブ・小さなラベル) | #E5A87A(ピーチ)。接客シートのタブはピーチ、お金シートのタブはゴールド #C6A85A | 講座LPの「このプログラムを受けると」 |
| 文字 / 補足の文字 | #544842 / #80766C | 両LP共通 |

ピーチは白い文字を載せると読みにくいので、広い帯には使わない。

## ユーザーが「全部やる」と決めた改善(2026-09-30)
1. 1〜3ヶ月目(お金)に「つい使ってしまったお金」欄を追加。横に「使ってよかった/なくてもよかった」のプルダウン。
2. 3ヶ月パーソナルプラン(お金)の「貯金できた金額」を1か所にまとめる(11行目と I〜J 列の表が重複)。
3. 受講生名・勤務形態・講座開始日・売上の目安は「パーソナル情報」に1回書き、他シートは数式で参照。
4. 入力欄と計算欄を色で分け、計算欄は保護(警告のみ)。
5. 「目安との差」は色だけでなく文字でも示す(「目安クリア」「あと◯円」)。赤で責める見せ方はしない。
6. 週の表の「期間」を講座開始日から自動で入れる。「1Week」→「1週目」。
7. 勤務形態・給料形態をプルダウンに。
8. 共有は受講生ごとにコピーして、本人とみずきさんだけに共有(運用の話。ユーザーに伝えるだけ)。

基本は「接客」で使う。お金の欄は希望者だけ(見られたくない人に強制しない)。
