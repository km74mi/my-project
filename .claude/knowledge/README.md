# 知識メモ

ここに置いた `.md` は、セッション開始時に `.claude/hooks/session-start.sh` が毎回 Claude に読み込ませる(README.md は除く。1ファイル先頭 4000 文字まで)。

- 1テーマ1ファイル。ファイル名は内容がわかる英小文字とハイフン(例: `user-preferences.md`, `decisions.md`)。
- 書くもの: ユーザーの好み・決めたこと・前回の作業でわかった注意点など、次の作業でも前提になること。
- 手順として繰り返し使うものはここではなく `.claude/skills/<名前>/SKILL.md` にスキルとして書く。
- **このリポジトリは公開。** 個人情報・API キー・写真・非公開の数字は書かない。
