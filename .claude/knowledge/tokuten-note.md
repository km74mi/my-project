# 個別面談につなげる特典 note(2026-10-06 作成中)

LINE 登録などで渡す特典を note の記事で作っている。目的は**個別面談の申し込み**。

## 決めたこと
- 講座の紹介ページ(LP 代わり)にはしない。講座の説明は最小限にして、面談に来たくなる文章にする。
- 「講座を作った理由」の話は主役にしない。みずきさんの体験は、読む人の悩みへの共感・裏づけとして使う。
- 訴求は「掛け持ちで続けるのしんどいよね」「無理して続けるのしんどいよね」。「接客スタイル」推しは集客につながりにくいので前に出さない。
- 発信軸(2026-10-06、相談相手のアドバイスで決定):「掛け持ちでも、お客様に振り回されず、主導権を握って無理せず稼ぐ」。媚びない・疲弊しない。
- アンケートで体力の悩みは 0%。「疲弊」は体力(寝不足・くたくた)の話にせず、「時間と気持ちを奪われる/振り回される」で表現する。
- みずきさんの強み:「今日は行けない」「今日じゃなく明日来てほしい」と自分でコントロールしながらお客様を掴める。
- note は「もらうだけ」で読めるのが利点(Q&A会などは参加のハードルが高い)。講座への想いも入れて、面談につなげる。
- 口調はみずきさんの一人称「私」。関西弁は強くしすぎない(ほぼ標準語+やわらかい語尾、「しんどい」程度)。
- 参考にした他の人の note は構成だけ参考にし、言い回しはまねない。

- 「主導権」は言葉が硬いので使わない。お悩み相談会のタイトルに合わせて「選ばれる側から“選ぶ”側へ」「自分のペースで」と言い換える。
- 「いやいや働くより、せっかくなら楽しく稼ぐ」を入れる(面談LPの「無理して続ける」を「楽しく続ける」に、と同じ方向)。
- 有益情報は講座本編と被らせない。特に 02「接客スタイル迷子」、03「他責思考」、08「時間の使い方」(隙間時間など)とは別の話にする。読む人が自分で振り返るチェック程度にとどめる。
- 掛け持ちを接客で話していたら「明日早いから休み」が通じ、「昼もちゃんと働いてる子」とイメージが上がった(みずきさんの体験。note の見せ場)。
