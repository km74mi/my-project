# リールの台本作り(みずきさんと壁打ち)

みずきさん(現役キャバ嬢・元先生・昼夜掛け持ちで13ヶ月連続No.1)のインスタのリールの台本を、壁打ちしながら作る手順。
2026-10-10 に、ユーザーがそれまで claude.ai のプロジェクト2つで続けてきた壁打ち(台本作りと、台本ができていく過程)を貼ってくれたので、そこからまとめた。貼られたのは一部だけなので、新しい壁打ちが届いたら足していく。

- みずきさんの語り口・考え方・これまでの台本の傾向 → `references/voice-and-thinking.md`(台本を書く前に必ず読む)
- 完成した台本の例と、参考動画の分析の例 → `references/examples.md`
- インサイトの傾向(男女比など) → `.claude/knowledge/reel-insights.md`
- 面談導線のリール(30秒・テロップだけ)の台本 → `.claude/knowledge/reel-scripts.md`

## まず形式を確かめる
台本には形式が2つある。どちらの話かで、長さも書き方も全く違う。分からなければ聞く。

| | いつもの語りのリール | 面談導線のリール |
|---|---|---|
| 映像 | 料理などの映像+みずきさんの語り(顔は出さない) | 顔の映らない映像+テロップだけ。声なし、流行りの音源 |
| 長さ | 約40秒〜1分 | 30秒 |
| 文字数の目安 | 本当の文字数で約430〜500文字(改行を除く) | 画面の数と秒数で決める(1画面1秒前後) |
| 冒頭 | 「私は先生を辞めた、現役キャバ嬢32歳」+その回の一言タイトル | 「キャバ嬢」を入れた問いかけ |
| 目的 | 閲覧・保存・フォロー | 「◯◯とコメント」→ DM で note → 面談 |

## 流れ
1. **ジャンルを聞く。** 一人語り(スズキタゴサク構文など)/お客さんとのやり取り・トラブル/彼氏とのケンカなどのストーリー/背徳飯などの料理モノ/働き方・掛け持ちの話。選択肢を出して答えやすくする。
2. **参考動画があれば分解する。** 文字起こし(タイムスタンプ・テロップ・話し言葉を分けた表)をもらって、
   - 抽象: なぜ伸びたかを3〜4個の「構造」で言う(例: 罪悪感×快楽、低い情報コスト、音の快楽、正論への先回りツッコミ)。
   - 具体: 一文ずつ「視聴者が感じること」「自分ごと化する瞬間」を表にする。
   - 一番の勝因を1つに絞って言い切る(例:「ダイエットは明日から」で他人の飯テロが自分の話になる)。
   - 最後に「みずきさんの台本ならどう使えるか」を一言。
3. **「うち風」に書き換える。** 参考動画の構造(テンポ・オチの位置・行数)はそのまま残し、中身をキャバ嬢の生活に置き換える(深夜2時の帰宅、メイクを落とさず、チューハイ、太客のLINE、指名)。決めゼリフはキャバ嬢の自虐に変える(「ダイエットは明日から」→「ダイエットは指名増えてから」)。テーマと尺は先に選択肢で聞く。
4. **たたき台を出す。** 表(タイムスタンプ/テロップ/セリフ)か、そのまま読める改行の台本で出す。「変えたポイント」を箇条書きで添え、「たたき台やから、みずきの声で気になるとこ言うて」と返す。
5. **辛口添削する(頼まれたら、または台本が届いたら)。** 順番は「文字数 → 良い点 → 直したほうがいい点(番号つき、理由と書き換え例) → 確認したいこと」。書き換え例は仮のものと断り、実際の体験はみずきさんの言葉で書いてもらう。
   - よく出る指摘: 「なぜそうなったか」の理由が抜けている/締めが本文とずれている/述語が抜けて文がつながらない/重い話(身体的な被害など)を軽いノリで終わらせている/フォローやコメントの導線がない。
   - 誘導は1本にする。「コメント」と「フォロー」を同じ動画で頼むと両方弱くなる。フォローは投稿の文章(キャプション)で頼む。
6. **文字数を数える。** 下の「文字数の数え方」で。
7. **完成版を出す。** みずきさんが「これで完成」と言ったら、その版を `references/examples.md` に足す(公開してよい台本だけ)。
8. **投稿後のインサイトを分析する。** 数字のまとめ→前の回との比較→視聴維持率のグラフ(どこで離れたか)→気になる点→次の台本への提案。男女比や流入元など、分かった傾向は `.claude/knowledge/reel-insights.md` に足す(数字そのものは書かない)。データが足りないときは「オーディエンスタブの性別の画面を送って」と具体的に頼む。

## 文字数の数え方
日本語1文字を1と数え、改行は除く。

```bash
python3 -c "import sys;t=sys.stdin.read();print(len(t.replace('\n','')))" < 台本.txt
```

`wc -m` は環境によって日本語1文字を3と数える(バイト数になる)ので使わない。以前の壁打ちで出てきた「成功レンジ 1,270〜1,500字」はこのバイト数で、本当の文字数にすると約430〜500文字。

## 話し方
- 関西弁でフランクに(「〜やで」「〜やな」「どうする？」)。みずきさんの台本の一人称は「私」(セリフや語りの中の関西弁はそのまま)。
- 褒めるところは具体的に褒めてから直す。直すときは理由と書き換え例をセットにする。
- 決めるのはみずきさん。迷うところは選択肢を出して聞く。
