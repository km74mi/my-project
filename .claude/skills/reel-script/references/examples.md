# 台本と分析の例

## 完成した台本: 客から不倫相手に選ばれた(いつもの語りのリール、440文字)
```
私は先生をやめた現役キャバ嬢32歳
客から不倫相手に選ばれました。
彼女が欲しいって言う客(29)の恋愛相談にのってたんですね。

話を聞いてたら、なんとなく私の第六感が「やばい気がする」って言ってきたんですね。
だから「結婚願望はあるん?」と聞いたら
「あ、俺結婚してるよ」と衝撃発言
しかも！1歳と2歳の子どもがいたんですよ！
いやいや、なんでこんなとこに来てんねん!
とか、彼女ほしいとか、ツッコミどころ満載。
しかも「俺も誰にでも言ってる訳じゃない」っていうクズプライドを語ってきやがった。

「みずきちゃんやから言った」って
謎に不倫相手に選ばれたんですね。
完全、ちょろい女って思われてる。

「家族にも全力で、彼女にも全力で」
とか言い出したので

え、ここ日本なんですけど
一夫多妻制という新しい文化を日本に広めようとしてます？
そんな盛大なプロジェクトに携わる気はさらさらないので、
「未婚の男がいいな」ってキッパリ断りました。

その客(クズ男)消防士でした。
やっぱり 3Bと3Sには気をつけないとですね。
```
型: 冒頭の自己紹介+タイトル → 状況 → 違和感(第六感) → 衝撃の事実 → ツッコミ → 相手のクズ発言 → 大げさな言い換えのツッコミ → きっぱり断る → オチ。

## 参考動画の分析の例: 「背徳の豚ラーメン」(他の人の動画、約40秒・234万回)
- 抽象: ①罪悪感×快楽(マヨ・ニンニク・卵黄・ラー油・ビール) ②手順が単純で離れるところがない ③「うまっ」の短い反応が3回 ④正論への先回りツッコミ(「味は濃いほど美味い」「ダイエットは明日から」)。
- 一番の勝因: 「ダイエットは明日から」。他人の飯テロを見ていただけの人が「自分も言うてるやん」と自分ごとにする瞬間。
- 冒頭の「うまっ」は、オチ(美味しさ)を先に見せる掴み。
