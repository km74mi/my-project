# みずきのライフプラン を直す・作るときの手順

## まず読むもの

1. `lifeplan-app/README.md`(構成・書き出し・写真の扱い)
2. 変更内容に応じて `lifeplan-app/docs/` の該当ファイル
   - 画面 → `02_画面構成.md`、計算 → `03_計算ロジック.md`、見た目 → `04_デザイン.md`、数字の出どころ → `05_仮の数字と確認事項.md`

## 守ること

- **写真を公開リポジトリに入れない。** ソースは `__MZ_IMG__` の目印のまま。写真入りの `dist/index.html` はコミットしない。
- **みずき相談ルームと同じデザイン**(ローズ×ゴールド、Shippori Mincho / Zen Kaku Gothic New / Cormorant Garamond イタリック)。色は `:root` のトークンで持ち、ライト・ダーク両方を定義する。
- 画面の説明・解説は標準語。みずきさんの吹き出しだけ関西弁。責めない言い方にし、目安であることを添える。
- 数字が苦手な人が最初に見るのは「今月貯めたいお金」。新しい数字を足すときは、それより目立たせない。
- 仮の数字を足したら `docs/05_仮の数字と確認事項.md` に書く。根拠のない数字・体験談を「事実」として書かない。
- グラフ:左右で単位が違う2軸は使わない。色を増やすときは dataviz スキルの `validate_palette.js` でライト(背景 #FFFCFA)・ダーク(背景 #272021)両方を検証する。状態は色だけでなく文字や「!」でも示す。
- 入力は端末の localStorage にだけ保存(キー `mizuki-lifeplan-v3`)。保存形式を変えるときはキーの末尾の数字を上げる。

## 作業の流れ

1. `lifeplan-app/src/lifeplan.src.html` を直す(React 18 + htm。CSS → データ定義 → 計算 → 画面部品 → App の順に並んでいる)。
2. `python lifeplan-app/build.py` で `dist/index.html` を作る。
3. `node lifeplan-app/scripts/check.js` でスマホ幅・ライト/ダークのスクリーンショットを撮り、目で確認する。
   - CDN に届かない環境では `npm pack react@18.3.1 react-dom@18.3.1 htm@3.1.1` などでローカルに用意すると、スクリプトが差し込む。
   - 見るところ:ページのエラーがない、`scrollWidth=390`、文字の重なり・はみ出しがない、ツールチップが出る。
4. アーティファクトを更新する場合:写真入りで書き出したファイル(`assets/mizuki.jpg` を置いてから `build.py --output <作業用の場所>`)を、既存の URL(README 参照)に publish する。写真の元データは、みずき相談ルームのアーティファクトの `--mz-img` からも取り出せる。
5. 変更内容に合わせて `docs/` を更新する(特に 02・03・05)。

## よくある変更の場所

| やりたいこと | 場所(src 内の名前) |
| --- | --- |
| 叶えたいことの項目・目安の金額 | `EVENTS` |
| 卒業後の道と手取りの目安 | `AFTER` |
| 支出の項目・ひとり暮らしの目安 | `EXPENSES`(`work: true` は卒業後になくなる経費) |
| 入力例(ペルソナ「あい」) | `SAMPLE` |
| 1年ごとの計算 | `simulate` |
| 「今月貯めたいお金」カード | `heroNumbers` / `Hero` |
| タイプ診断と充足率 | `diagnose` / `Meter` |
| もしも比較 | `scenarios` |
| 数字を変えて未来を見る | `applyWhatIf` / `WhatIf` |
| 自動の解説文 | `decadeComment` / `savingsComment` / `adviceParas` |
| みずきのひとこと | `Result` の中の `Say` |

## 同じ考え方で別のアプリを作るとき

- 「質問(1問1画面、選ぶだけで目安が入る) → 結果の先頭に行動につながる数字1つ → 詳しいグラフと表 → 数字を動かして変化を見る」の順が、数字が苦手な人に届きやすかった。
- 参考サイトの見せ方(タブ、ツールチップ、10年ごと、「!」の目印、条件別アドバイス)は、ユーザーが画像で共有したものを取り入れた(`docs/06`)。
